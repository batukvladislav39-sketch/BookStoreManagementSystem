# BookAbyss — Інструкція запуску

### 1. Створення та активація віртуального середовища

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 3. Налаштування бази даних

Переконайтеся, що MySQL Server запущений, база даних створена, а параметри підключення налаштовані у файлі `.env`.

### 4. Застосування міграцій

```bash
python manage.py migrate
```

### 5. Запуск системи

```bash
python manage.py runserver
```

Відкрийте браузер і перейдіть за адресою:

http://127.0.0.1:8000/

**Примітка:** команди виконуйте в терміналі з кореневої папки проєкту, де розташований файл `manage.py`.
